# Demo · Registering an expense

A four-scene example of the manuscript format. `[tags]` set the voice's tone,
`{cues}` are actions on screen and are not read aloud, and `{trin: N}` shows
the step badge.

## Scene 1 · Title

*Screen:* Title card.

```speak
[warmly] Welcome. This short video shows how to register an expense.
```

## Scene 2 · The process

*Screen:* The process with its three phases. Phase 2 lights up.

```speak
[calm, clear] Expenses go through three phases. {fremhæv: phase 2} This video covers the second one: registering.
```

## Scene 3 · Register

*Screen:* The expense form. The amount is typed, Save is clicked, and the total is circled.

```speak
{trin: 2} {skriv: Amount} Type the amount, [pauses] {klik: Save} save it... {ring: Total} and the total is updated straight away.
```

## Scene 4 · End

*Screen:* End card.

```speak
[warmly] {vis: slutkort} That was it. Thanks for watching.
```
